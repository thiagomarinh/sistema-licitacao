Mostrar marcadores ▼

Abra sua declaração no Word e substitua os dados variáveis pelos marcadores abaixo (com as chaves duplas). O sistema preencherá automaticamente ao gerar.

{{ '{{nome_empresa}}' }} Nome da empresa
{{ '{{cnpj}}' }} CNPJ
{{ '{{responsavel}}' }} Nome do responsável/sócio
{{ '{{cpf}}' }} CPF / RG do responsável
{{ '{{endereco}}' }} Endereço completo
{{ '{{telefone}}' }} Telefone
{{ '{{data}}' }} Data atual (DD/MM/AAAA)
{{ '{{data_extenso}}' }} Ex: 9 de abril de 2026
{{ '{{num_pregao}}' }} Nº do Pregão (da composição)
{{ '{{num_processo}}' }} Nº do Processo Administrativo
